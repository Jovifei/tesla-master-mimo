# MateLink Web 设计 v3（WEB-DESIGN-V3）

> 状态：设计定稿（本阶段只设计，不写代码）。本文件取代 `docs/WEB-DESIGN.md`（v2）在**布局、视觉、图形、动效**上的全部结论；v2 的诚实约束（不许发明数据、指令开关现实、胎压只认 bar 与本地稀疏采样、驻车耗电须严格证明、聚合必带覆盖、快照即一等公民）继续有效，并入 §2.8 与各页规格。
>
> 业主否决史：v1 是文字列表；v2 把手机 App 的槽位排得更漂亮——本质仍是 App 信息架构的放大。本版从第一性原理重做：先问每个模块**做什么**、每个参数**意味着什么、支撑什么决定**，再推导桌面布局。手机回答"现在怎么样"，桌面回答"**为什么、多少钱、证据在哪、下一步怎么办**"。

## 0. 方法与输入

**团队过程（五轮 panel，每轮书面批评上一轮，协调者裁决冲突）：**

1. **IA/UX 轮**——逐页 JTBD、到达问题、全部参数按"含义 → 支撑的决定 → 瞥视优先级（P0/P1/P2）"分类；无决定支撑的参数降级或砍掉。
2. **布局轮**——桌面原生格局（宽画布、悬停、键盘）；仪表盘三案（bento / 摘要带 / 主从）评选；定网格、外壳、逐页线框与 px 尺寸。
3. **视觉轮**——身份、字体、图标、颜色、间距、圆角、阴影、材质；对布局的视觉性异议（尺寸预算、色板、图标）。
4. **DataViz 轮**——逐个到达问题裁决"图 / 数字 / 表"；对 IA 与布局的图形构造行使否决权（双轴、月度图、距离色验证）。
5. **动效轮**——什么动、多久、什么永不动；对前四轮动效条款逐条过堂（含否决布局的页面切换淡入淡出）。

**理论依据（点名引用，施工与评审时可回溯）：** Refactoring UI（视觉层级靠字重与颜色先于字号、间距成组、阴影克制）；Laws of UX（Fitts、Hick、Jakob、Von Restorff、Peak–End、5 秒测试）；Tufte（data-ink ratio、graphical integrity / lie factor ≈ 1、small multiples、sparklines、direct labeling、chartjunk）；FT Visual Vocabulary（图随关系选：随时间变化→线、相关→散点、构成→条）；Cleveland–McGill 知觉排序（共同标尺上的位置 > 长度 > 角度/面积 > 颜色）；Gestalt（邻近、相似、共同区域）。

**frontend-design skill 的约束（两遍法：先立身份、再逐条自查默认 tell）：** 本版身份取自被设计物本身——**「安静的账本，精确的仪表」**（账本的栏线、仪表的刻度、行车日志的行）。明令回避的 AI 默认 tell 及本版对策：等大圆角卡片套装（→ §2.1 尺寸按重要性分级、等大即失败信号）；渐变洗色（→ 全站无渐变，面积填充只许刻度带的平色一段）；大数字+渐变 hero（→ 唯一的大胆装置是刻度带，见 §2.4）；ALL-CAPS 眉题（→ 取消眉题，标题靠字重）；等宽字体数据标签（→ 删除 mono 令牌，数字用系统无衬线 + tabular-nums）；中点分隔的元信息串（→ 元信息各就各位：前提进前提带、注记进预留注记槽）。

## 1. Panel 讨论纪要

### 1.1 IA 轮（第一棒）：桌面不是放大的手机

- **总纲：** 手机端是状态机（现在怎么样），桌面端是复盘与取证台。每页先定 JTBD 与"用户带着什么问题到达"，再给每个参数定档。到达问题答不出、或参数支撑不了任何决定的，降级或删除。
- **仪表盘 = 分诊台**，不是展示柜：只答四个结论（电够不够、数据新不新、车安不安全、车在哪 / 在充什么），答完即分流到各证据页。
- **三个会话原型**（决定各页权重）：A 周日晚复盘（最高频，分析优先，仪表盘不是必经大厅）；B 充电中监控（陪伴型会话，要实时性与"数据多旧"的绝对清晰）；C 出发前检查（只看仪表盘四个结论）。
- **关键裁决：** 续航只认 estimated（rated 降为规格折叠项；且**禁止 `rated ?? estimated` 之类的回退合并**——现行代码把两者合并显示，是信息错误）；`speedMaxKmh` 定性为虚荣参数（降为取证明细文本行，永不进 KPI 与任何图形）；单价（元/kWh）是充电页缺失的派生 P0（现行不存在，须前端派生）；控制页按**功能**分组而非风险层级，解锁单列危险区；"我的"页必须新增**授权治理区**（现行是死胡同：控制页把人支到"我的"，到了却无事可做）；地点管理从仪表盘移至"我的"。
- **参数通胀自检：** 本轮给各页定的 P0 数量在下一轮被布局轮再切一刀（P0-a / P0-b，见 §1.2）。

### 1.2 布局轮：主从格局胜出，自上而下批评 IA

- **仪表盘选案：(b) 主从式——左结论轨 360px + 右证据区。** bento 落选：固定网格装不下"按异常重排"的内容，且等大倾向正是被否决的 v2 病根；摘要带落选：横带内部天然等权，且与分析页结论行撞形。主从的左轨是"结论"，右区是"证据与去向"，层级由结构本身表达，不靠装饰。
- **批评 IA 并被采纳：** P0 拆为 **P0-a（结论，进 hero / 结论行）** 与 **P0-b（前提与上下文，进固定行位）**——前提类信息（快照来源、覆盖）若与结论同台竞争，5 秒测试必败；KPI 磁贴形态**整体废除**（它是等大卡片套装的化身）；Ring 限量保留（仪表盘 136 / 充电实时 112）——此条后被视觉 + DataViz 两轮推翻（见 §1.6 裁决 2）。
- **外壳革命：** 取消 216px 侧边栏，改 **56px 顶栏**（会话 B 的充电状态丸常驻顶栏）；内容最大宽 **1400**；新鲜度前提带定高 36（后被视觉轮以行高数学改判 32，见裁决 1）；跨页深链一律走 URL 参数；键盘只留 3 个快捷键（`/`、`r`、`?`），指令不给快捷键（不可逆动作不配肌肉记忆）。
- **两条施工纪律：** 骨架与内容同形同高（骨架不是占位灰块，是内容的轮廓）；字段不成立时"**消失的是数字，不是行**"——行位以原因行形态保留（如驻车耗电未通过严格证明时，36px 原因行照在）。

### 1.3 视觉轮：身份、刻度带、蓝与 teal 的分工

- **身份：** 「安静的账本，精确的仪表」。全站唯一的大胆装置定为 **Charge Ruler（电量刻度带）**：0–100 水平标尺，teal 平色填充至当前 SOC，2px 深 teal 读数线，续航数字在读数线上方对齐。它只出现两处：仪表盘 hero 底部、充电页实时区顶部。
- **推翻布局轮两处：** ① **Ring 废除**——渐变环是 chartjunk，且"大数字 + 圆环"正是 skill 点名的默认 hero 造型；刻度带以"线上的位置"编码同一数值，知觉精度更高一档。② **新鲜度带改 32px**（8 内边距 + 16 行高 + 8 内边距，字体系统的行高数学说了算）。
- **颜色分工（本版最重要的视觉裁决）：** **tint 蓝 #0071e3 只表示"可点"**（按钮、链接、选中、焦点）；**teal #157a86 降为纯数据色**（只出现在 SOC 刻度带、能量曲线、充电功率数字上——teal 读作"电"，不读作"点我"）。v2 的 teal 主按钮必须改蓝。等宽字体令牌删除。
- **层级手法：** 先后顺序是字重（400/500/600）→ 颜色（label / label-2 / label-3）→ 最后才是字号；正文 17px（桌面阅读距离）；覆盖注记的降权只许用字重 + 颜色，**永不许用字号**（缩小字号 = 把诚实做小）；异常配额制：全页至多一个填充面（严重度排序 解锁 > 开窗 > 胎压），其余异常只配文字行。
- **圆角之争的解法：** digest 主张同景一致、skill 主张按角色分化——裁决为"**同一构成层级内恒定、跨层级分化**"（§2.5 尺表）。
- 深色模式：本期不做，v2 的自动深色关闭；令牌保持语义命名以便将来映射。

### 1.4 DataViz 轮：对 IA 与布局行使图形否决权

- **否决双轴（全站无例外）：** IA 与布局原案的"功率 + SOC 同图双轴"（充电）、"速度 + 功率同图"（行程）全部作废。双轴下两线相对斜率由右轴任意缩放决定，lie factor 不可控；且一图答两问违反 one question per chart。落法是**竖叠分图、共享 x 轴、游标贯穿**，且总高度一像素不加（充电 300 = 功率 196 + SOC 80 + 轴 24；行程 412 = 功率 148 + 速度 108 + SOC 64 + 海拔 68 + 共享轴）。SOC 与海拔**并排**方案同样否决（共享时间的取证要竖叠对齐，不要并排对照）。
- **月度图不存在：** 分析页月度对比由**宽表**承担（12 点 × 六个对账量要的是确切值；柱图会把多币种 null、缺失、覆盖不全画成 0 或断柱）。digest 提议的 2×2 月度 small multiples 一并驳回（月度效率与月度覆盖数据不存在，缺格的 multiples 是假图）。260 高的下钻槽保留，改作双态证据图（§3.5）。
- **距离色验证不通过：** 视觉轮暂定的"距离用蓝深色变体"经三邻位检验（与链接/选中同屏、小面积线条形态、与 teal 相邻）判定会侵蚀"蓝 = 可点"契约——同色相只差明度，小面积上分不清。**距离改入石墨阶 #48484a**，全站数据色相收为 2 族（teal + 石墨灰阶）。
- **"默认灰"原则背书 + 取证态例外：** 概览态只给被讨论的系列上色；但取证态（详情联动面板展开时）每格主系列一律全对比度——异常常藏在被灰掉的邻居里（电压先 sag、功率才塌），降灰只许作用于同格的对照上下文。
- **coverage 永不图形化（专条）：** 完整度只许以"基于 186/214 条记录"的分数文字出现。任何环、条、点阵都会藏掉分母、把确切整数压成不可核验的面积，还会与 SOC 百分比形态撞车被误读为车辆状态。
- **Sparkline 议题关闭：** 除充电三小图的"索引条"（带数值锚点的形状线）外，全站无合法 sparkline——仪表盘没有序列可画，列表行的小线只提供虚假趋势感。
- **Ring 之争站视觉：** 圆环的角度编码在知觉排序里比位置编码低一整档；裁决刻度带为 SOC 的权威图形编码（协调者据此结案，见 §1.6 裁决 2）。

### 1.5 动效轮：静，是这套系统的动效性格

- **否决布局轮的页面切换淡入淡出（≤150ms crossfade）：** 读数型产品里页面切换 = 换一张报表，交叉淡化平白加一帧"内容不可读"的时间。裁决 **0ms 瞬时切换**；仅当出现白帧时允许 80ms 单向淡入作兜底。
- **刻度带首扫是全站唯一的"编排时刻"（Peak–End）：** 填充以 scaleX 扫至读数值，720ms ease-out，**整会话只播一次**（仪表盘与充电页共享标记）；数字从第一帧就是终值（禁数字滚动——那是老虎机，不是仪表）；**快照数据上永不播放**（给旧数据配动画等于暗示它是活的）；reduced-motion 时直接呈终值 + 120ms 淡入。
- **指令反馈不是第二个峰值：** 已受理/成功只配 160ms 的对勾 + 文字替换，禁止成功庆祝、禁止 teal 填充成功态。实时数字只许直变（无滚动无补间），功率读数 ≥5 秒节流聚合；标签页隐藏时一切停止，切回不补播。
- **禁令清单（永不出现）：** 悬停抬升/阴影/缩放、逐区块入场、数字滚动计数（刻度带填充除外）、呼吸/脉冲光点、骨架微光扫过（shimmer）、抖动、视差/倾斜/辉光、图表生长动画（库动画默认关；仅当页 hero 图在本会话首次得数时可申请 ≤600ms 描画，柱永不生长，小图/点图永不动画）。
- **验收法：** 每页录 5 秒屏——除刻度带首扫外，画面应当是静止的。

### 1.6 争议裁决表（协调者结案，落败方观点存档）

| # | 争议 | 裁决 | 理由与存档 |
|---|---|---|---|

## 2. 全局设计系统 v3

### 2.1 外壳与网格

| 项 | 值 | 说明 |
|---|---|---|
| 顶栏 | 高 **56**，全宽，毛玻璃材质（§2.5） | 左：产品名 + 车辆切换；中：六页导航（文字 + 20 图标）；右：**充电状态丸**（会话 B 常驻；充电时 teal 数据字 + 已充时长，点击跳充电页实时区）+ 手动刷新 + 账号 |
| 侧边栏 | **取消** | 216px 侧栏是 App 思维；桌面导航收进顶栏，画布全给内容 |
| 新鲜度前提带 | 高 **32**（8+16+8），顶栏下全宽，六页恒在 | 左：来源点 + 来源字（实时 = 透明底 + 8px 绿点；快照 = warning-soft 平色底 + 深琥珀 #6e4200 字，**无关闭按钮**）；中：观测时刻 + 相对时间；右：手动刷新按钮。快照不是故障，是数据性质，必须逐字可读 |
| 异常带 | 前提带之下、内容之上，全宽；**无异常时高 0** | 至多一个填充面（§2.4 配额）；高度内容驱动 ≈76–92；展开/收起走 §2.6 的高度动画例外条款 |
| 内容最大宽 | **1400**，页边距 32 → 内容区 **1336** | 超宽屏不拉伸：账本与仪表的行宽有上限 |
| 参考网格 | 12 栏，沟槽 **16**（视口 ≥1600 时可 24，全页只许一个值） | 栏格管"流式证据区"的对齐纪律；**固定宽区以 px 为准**（结论轨 360、充电 master 380、行程 master 360）——文本行宽与列表密度由功能定，不由栏格分数定 |
| 行高单位 | **U = 104**，行距（pitch）124 | Hero = 2U（208 内容 + 内边距 = 228 总高）；磁贴行高只许 U 的整数倍或半倍（52） |

**异常配额：** 每页至多**一个**填充面给异常（圆角 12 以区别于磁贴的 16）；多异常并存时按严重度排序（解锁 > 开窗 > 胎压），只给第一名填充，其余降为文字行。填充面上用深色相文字，**永不许灰字压彩底**。

### 2.6 动效

**总性格：静。** 动效的存在理由只有两个：解释状态变化、标示因果。其余一律砍。

令牌：`--dur-instant 80 / micro 120 / fast 150–160 / exit 195 / enter 225 / expand 200·250 / emphasis 300 / anchor 1200 / ruler 720`（ms）。曲线：出 `cubic-bezier(0.22,1,0.36,1)`，入 `cubic-bezier(0.55,0,1,0.45)`。弹簧只许用于手势可逆的动效（折叠、SegControl 滑块 160ms、主从选择），阻尼 ≈1.0 不回弹。**并发上限 2。**

| 场景 | 裁决 |
|---|---|
| 页面切换 | **0ms 瞬时**；仅白帧时 80ms 单向淡入兜底 |
| 刻度带首扫 | 填充 scaleX 720ms ease-out；**整会话一次**（两处共享标记）；数字首帧即终值；**快照数据永不播**；reduced-motion → 终值 + 120ms 淡入 |
| 指令反馈 | 对勾 160ms 出现 + 文字替换即全部；**禁**成功填充、庆祝、二次峰值 |
| 实时数字 | 只许直变；功率类 ≥5s 节流（窗口聚合值）；禁滚动、禁补间、禁秒级倒计时（全站无任何秒级倒计时） |
| 快照转实时 | 前提带一次性改色 195ms，不闪烁 |
| 深链锚点 | 目标 2px tint 描边 1200ms 单次淡出；目标在异常填充内时描边改用 label 色；永不许"闪烁提示" |
| 骨架→内容 | 直接替换 + 120ms 不透明度，逐块独立，禁交叉淡化串联 |
| 高度变化（异常带、展开格、折叠区） | 唯一许用手法：`grid-template-rows 0fr→1fr`（200/250ms）；禁 scaleY |
| 图表 | 库动画**默认关**（`isAnimationActive=false`）；每页 hero 图在本会话首次得数时可申请 ≤600ms 描画，数据更新永不动画；柱永不生长；小图/点图/胎压点永不动画 |
| 线性（linear）例外 | 只许三处：①刻度带填充跟随真实 SOC 增量（300ms）；②唯一的转圈（指令"受理中"，900ms/圈）；③将来真实字节进度 |
| 标签页隐藏 | 一切动效与节流计时停止；切回不补播、不回放 |

**永不动画清单：** 悬停抬升/阴影/缩放、逐区块入场、数字滚动计数（刻度带填充除外）、呼吸/脉冲点、shimmer、抖动、视差、倾斜、辉光、成功庆祝、数据图的生长与轴域 morph。

**验收：** 每页 5 秒录屏，除刻度带首扫外画面应静止。

### 2.7 图形通则（DataViz 施工律，全站图表适用）

- **图只做两件事：** 取证（为什么慢/为什么费）与看形状（趋势、分布、相关、慢漂移）。要确切数值、对账、当前状态的，一律数字或表。**没有序列就没有图**——状态接口只有快照，全站合法序列只有四类：单次充电采样、单次行程采样、年度/月度聚合、胎压本地稀疏样本。
- **禁双轴，无例外。** 多序列同时间轴：一律竖叠分图、共享 x、游标贯穿。
- **轴：** 柱/条从 0（lie factor ≈ 1，无断轴）；线图非零域须刻度印真实值、域算法写死（见各图规格）、**同一会话视图内永不自动重缩放**（筛选、游标、展开、刷新都不许改已呈现图的 y 域）。
- **线条：** 只用直线段连相邻真实采样点；禁样条/平滑；缺口（null 或间隔 > 该序列中位采样间隔 2 倍）**必须断线**。两端点之间永不许连线（驻车、SOC 首末同罪）。
- **采样降级（全站统一）：** ≥10 点正常成线不画点；3–9 点画点（r=2.5）+ 直线段 + 图注"本次仅 N 个采样点"；2 点只画点不连线；<2 点或全 null → 整图撤下，改数字行 + 一句原因。
- **零图例（legend）：** 系列身份靠面板标题与线端标注；关键值点旁直接标注（峰值 + 时刻、起止值），标注 12–13px label-2、数值 label 色 tabular-nums、距点 4–8px 不压线。合计数字进详情头，不压图内。
- **游标：** 1px label-3 级灰竖线（**禁用 tint 蓝**——蓝是交互色，且与选中行竖线撞语义），贯穿同组面板，吸附最近真实采样点（该点以系列色 r=3 标记）；读数**不做悬浮 tooltip**，固定呈现在图组上方读数行（时刻 + 各系列该时刻值），鼠标移出即灭、读数行回默认标注态。
- **网格：** 至多一组浅横线 3–4 条；无竖网格（竖线由游标承担）；无图框、无背景色块。
- **每图一问：** 每张图的标题须能写成它回答的那一个问题；答不出唯一问题即打回。
- **coverage 永不图形化**（§1.4 专条）：唯一形态 = 数字下方分数注记 + 不全时降权。禁环、条、点阵（waffle）、分段条。

### 2.8 诚实呈现通则（承 v2，继续有效）

1. **不发明数据：** 不存在的序列、聚合、口径，一张图一个数字都不许有（月度效率、哨兵耗电占比、SOC 历史线皆属此类，直到后端真实提供）。
2. **快照是一等公民：** telemetry_cache 快照以自己的来源与观测时刻正大光明呈现（前提带），不伪装实时、不配动画、不藏注脚。
3. **覆盖必随数字：** 一切聚合数字带分数覆盖注记；覆盖 <100% 时数字降权（字重+颜色）；视口过半降权时升为页面级覆盖声明。
4. **字段消失通则：** 资格不成立的字段（如未通过严格证明的驻车耗电）——**消失的是数字，不是行**：原位留 36px 原因行说明为何不显示。
5. **胎压纪律：** 只认 bar；本地样本稀疏（≥30 分钟间隔、上限 200 点），**只画点、永不连线**；样本不足时诚实结论作主角（五种结论措辞见 §3.5）。
6. **指令开关现实：** JOURVOLT_COMMANDS_ENABLED 关闭时，控制页的第一职责是解释"为什么不可用"，不是把灰按钮摆满屏（§3.4）。
7. **续航口径：** 只显示 estimated；rated 只进规格折叠；**禁止回退合并**（现行 `rated ?? estimated` 须改）。

### 2.9 跨页约定

- **刷新语义：** 手动刷新走后端唤醒链路；刷新中前提带呈"正在确认…"态；刷新失败保留旧数据 + 前提带注明失败时刻，**不清空页面**。
- **跨页深链：** 结论可点达证据：仪表盘异常行 → 对应页锚点；分析宽表费用 → 充电页按月筛选；控制页门禁提示 → "我的"治理区锚点（`#governance`）。落点描边见 §2.6。
- **三会话的前 10 秒：** A 复盘（直达分析，结论行四数先入眼）；B 充电监控（顶栏状态丸先行，充电页实时区刻度带 + 四数）；C 出发检查（仪表盘左轨四结论，右区可以不看）。

### 3.4 控制 —— 诊断优先的操作台

**JTBD：** 不是"摆满按钮"，而是先回答**能不能用、为什么不能、缺什么**，能用时按功能快速找到指令并确认结果。指令开关关闭是常态现实，本页设计以此为前提，不以此为例外。

**到达问题：** ① 指令为什么不可用（开关？授权？车辆状态？） ② 缺哪项授权、去哪补 ③ 某功能指令在哪一组 ④ 指令执行了吗、车辆读回了吗

**参数/对象优先级图：**

| 对象 | 档 | 处置 |

| 可用性诊断（开关状态 + 阻塞原因） | P0-a | 页首诊断区：结论句 + 阻塞链清单；关闭时这是本页的主角 |

**钻图槽 260 双态（协调者裁决 7）：** 态一（默认，未选月份）= **效率–温度散点图**：每点一段行程（须温度与单位能耗双全且 distanceKm ≥5，门槛与被排除数 n 在图注注明）；x 温度取整 5°C 含 0 线，y = kWh/100km 从 0；石墨点 r=3、透明度 0.75（重叠加深即密度）；**不画拟合线**（温度与能耗间混着速度、海拔、空调，模型不存在于数据里）；只许冬季（<5°C）/夏季（≥25°C）中位短横线 + 直接标注（"冬季中位 21.4 · n=38"）；y 最大离群点标日期 + 起终点简称（用户必追问的那一趟）。数据不足时本槽降级为**温度分档中位数表**（<0 / 0–10 / 10–20 / 20–30 / >30 °C 五档：中位能耗 + 样本数）。态二（点选某月）= **逐次单价点图**：x = 该月日期（每周一格），y = 单价从 0、上限取整 0.5 元；入图须 cost 与 energy 双全且 energy >0，排除数图下注记；点石墨 r=3，最高单价点直接标注（¥/kWh · 日期 · 站名截断），余点游标读数；可入图点 <3 → 本槽改呈该月会话表（时刻/站点/kWh/单价/总价）。两态永不同屏、槽高恒 260、切换无动画（直换 + 120ms）。

**胎压区施工：** TpmsCar 俯视图四轮值直接标注于轮位旁（常态 15px label-2；异常轮 17/600 深红），无图例无坐标（它是对照图不是图表）；每轮 observedAt 小字跟随，轮间观测差 >1 天升为注记。样本点图 = 四格 small multiples 竖排（每格高 44 + 格距 4，左列 FL/FR/RL/RR 标签 13px 定宽）：**y 域四格完全一致**（域 = 四轮全局 [floor((min−0.2)·10)/10, ceil((max+0.2)·10)/10] bar，刻度只在最上格印上下限）；**x 域四格完全一致**（四轮样本时间并集——每轮各自拉满是 small multiples 的头号造假）；每格只画 3px teal 样本点，格右注记"N 点"；首末差以文字进 verdict 区，**禁首末虚线**。样本 <10 或 spanHours <24：图区降级为只画点 + 大字诚实结论作主角——点照画，是为了让用户看见"为什么不足"，证据与结论同屏，但措辞由门槛定，不由图形观感定。

**状态：** 加载——结论行骨架带注记槽（槽位先行，防数字到位时跳动）；某数覆盖为空（known=0）——该数位呈"暂无可计记录"文字，不呈 0；页面级覆盖声明——当结论行过半数字降权时，声明行出现（36）；胎压样本为空——点图区呈"暂无样本（浏览本页时自动积累）" + 机制说明一行。

**排布理由：** 结论行四数对账在先（问题①④），宽表承问题②的主答案，下钻图只答"为什么"——聚合页的图必须向原始证据下钻才配存在，用月度柱图冒充下钻只是把导航画成图。散点是全站唯一合法散点：相关问题只有分布能答，两个季节均值会把离群与疏密压没。

### 3.6 我的 —— 审计台

**JTBD：** 管授权、管会话、管地点、管数据：一切"我把什么交给了这个产品、它现在是什么状态、出问题去哪修"的总台。控制页的门禁提示最终落在这里，**治理区是本页 hero，不是设置列表的一行**。

**到达问题：** ① 特斯拉授权还在吗、范围对吗、何时核验的 ② 虚拟钥匙配了吗 ③ 指令为什么被门禁挡住、缺什么 ④ 登录会话有哪些、要不要退出 ⑤ 我的地点（围栏）怎么管 ⑥ 数据导出与账号处理

**参数/对象优先级图：**

| 对象 | 档 | 处置 |
|---|---|---|
| 授权状态（已授权范围逐项 + 最近核验时刻） | P0-a | 治理区主块；状态结论必须带证据时刻，**禁止无据的"已绑定"绿点式结论** |
| 虚拟钥匙配对状态 | P0-a | 治理区内，与授权分开陈述（两者是不同的门） |
| 指令门禁缺口（与控制页同一份清单） | P0-a | 治理区内直达修复动作（重新授权等） |
| 重新授权 / 补授权动作 | P0-a | 治理区主按钮（tint 蓝）；走官方 OAuth，永不出现密码字段（红线） |
| 会话列表（设备/时间/当前标记）与退出 | P1 | 表格行；当前会话标明 |
| 地点（围栏）管理 | P1 | 列表 + 增删改；自仪表盘移入（§3.1） |
| 邀请/绑定关系 | P1 | 行式陈述 + 证据时刻 |
| 数据导出 | P2 | 动作行（与分析页导出同口径说明） |
| 头像装饰 | 砍 | 删除 v2 的头像表演位；账号以文字行陈述 |

**线框（单栏，宽 ≤1080）：**

```
┌─ 治理区 #governance（授权逐项 · 核验时刻 · 钥匙 · 缺口 · 动作）≈260 ┐
├─ 会话区（表）───────────────────────────────────────┤
├─ 地点区（围栏列表 + 编辑）────────────────────────────┤
└─ 数据与账号区（导出 · 退出 · 版本）────────────────────┘
```

**状态：** 授权失效/过期——治理区升为异常样式（本页唯一填充面让给它）+ 控制页诊断区同步；核验中——治理区呈"核验中"行位，旧结论保留并注明时刻（不清空）；未登录——整页即登录页（登录态规范不在本文件范围，沿用现行 OAuth 流程）。

**排布理由：** 治理区居首且做成块而非行：用户到这页多半是被控制页"支"来的，带着一个明确的缺口——第一屏必须接住它。状态结论带证据时刻是把 §2.8 的诚实通则用到账号域：没有"刚刚核验过"的状态不配用现在时陈述。
