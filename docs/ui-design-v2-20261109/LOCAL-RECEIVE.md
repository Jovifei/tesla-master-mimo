## 一次性独立核对

1. 在新的独立worktree接收最终SHA，记录commit/tree/parent；比对最终CI run/job/artifact。
2. 安装与运行只在隔离环境：Pillow==12.3.0、playwright==1.57.0、Chromium和可用的中文字体；`python build.py`、`python test.py`。不要更改Jovi系统字体/网络/代理；字体条件缺失如实记录。
3. 对照原始App截图核查保留项，不以文字清单代替页面检查；对比App与小程序共同页。检查登录CTA、四轮图、充电单位、日期切换和局部滚动。
4. 汇总一个报告返回原会话：版本、各项PASS/FAIL、截图/时间码、缺口。不修改业务代码、不自行实现Figma修复、不重复要求Jovi逐页下指令。
