# MateLink V2：以原 App 为基准的奶白统一设计

本轮 Owner 要求优先于 V1：小程序与 App 的相同功能使用相同布局、组件、单位、状态与交互；只有既有登录/授权、平台边界和不支持的功能可以不同。V1 过度删减首页，不作为本轮实施依据。

## 已完成与未完成

## 颜色方案（自定义设计候选，不是 Apple 指定色值）

A 推荐：背景 #F3F2EE，卡片 #FFFEFA，凹陷区域 #EEEDE9，文字 #232528，次要文字 #62666C，少量链接/图表强调 #41658D。主按钮石墨色，不再铺满青蓝。
B：背景 #F1F5F9，卡片仍 #FFFEFA。浅蓝只作极淡背景，不做大面积蓝卡。
C：背景 #F5F5F7，卡片 #FFFFFF，作为最中性的参考。

## 交互规则

- 日期A：今天默认展开，昨天/前天独立折叠；允许同时展开比较，每日都有驾驶与驻车。
- 日期B：仅日期内容区域支持横滑；提供点击日期与前后按钮。轻微堆叠表达前后天，不做翻牌、旋转或自动播放。
- 日期C：日期栏切换、下方单日列表，没有堆叠。
- 柱状图更适合准确比较次数；日历格适合扫描活跃度，必须保留数值与图例，颜色不代表驾驶评分。
- 附近充电维持首页两站/摘要。点击导航只打开一个导航选择 sheet；查看更多才打开完整站点列表，不叠第二层弹窗。
- 主Tab立即切换；局部展开220ms；sheet 240ms；系统/手动减少动画均停用。数字不随机滚动，图表不动画补造数据。
- 原型所有控制只弹确认演示，不请求、不改变车辆状态。输入金额空值不是零，0.00为有效实际账单。

## 页面重绘明细

统计概览：加权汇总/覆盖范围。充电统计：充入量与账单覆盖。电池健康：续航基线估算与样本，不冒充诊断。里程：实际累计和年化估算分开。行程历史：直接复用行程页。长途旅程：已有分段归集。能耗：加权指标。费用：真实/估算/未知分开。续航：样本与估算置信边界。待机：SOC净变化与充电分开，未知能量留空。年度报告：年份/里程/覆盖与脱敏分享候选。数据状态：连接与各类数据就绪度分开。软件更新：App安装与小程序版本机制不同。哨兵历史：事件与录像可用性分开。设置：账号、显示、通知、规则和诊断分组。关于：真实版本/SHA/协议文本，不猜。
