# MateLink 微信小程序与 Android App 页面对齐审核报告

日期：2026-10-31

版本：微信小程序 `0.6.2`

## 结论

本轮页面级对齐完成。微信小程序现有 9 个顶层页面覆盖 Android App 的 35 个入口状态，现已统一子页面顶栏、返回行为、卡片层级、图标标题、摘要指标、筛选和操作区。数据来源、计算资格、分页、缓存、账号/车辆作用域、Tesla 授权及费用只读规则未改变。

本地源码、类型、构建和微信开发者工具synthetic回归全部通过。真实 Tesla 账号和微信绑定仍受外部授权条件限制；本报告不把开发者工具登录、synthetic数据或编译成功当作真实账号验收。

## 已完成的页面修复

### 共享视觉层

- 新增 `SubpageHeader`，分析、洞察、工具、Tesla 授权和法律页统一使用 Android 式圆形返回按钮、页面标题和车辆副标题。
- 为上述页面启用 `navigationStyle: custom`，消除系统标题与页面正文标题重复。
- 新增 `SectionHeading` 与摘要指标条样式，卡片标题统一使用 Material 图标、32rpx 标题和 24rpx 卡片内边距。
- 保留 `@use` Sass 导入，构建不再出现 `@import` 迁移警告。

### 核心四 Tab

- 仪表盘沿用 Android 的主车辆卡、电量/续航、状态 Chips、里程/位置、温度、胎压和当前充电层级。
- 行程页使用 Android 日期和距离筛选顺序，保留日期、距离、最高速度、能耗四列指标、趋势图和驻车详情。
- 充电页使用 Android 日期、类型、费用、位置、短充和更多筛选，保留长金额、币种、未知模式、详情和曲线入口。
- “更多”保持 Android 的数据分析、报告与导出、系统、账号与授权分组。

## 参数、来源与计算边界

本轮没有改动以下已验证逻辑：

- 历史记录按账号、API origin、稳定车辆 ID 和会话代次隔离。
- 行程距离、时长、速度、SOC、净能量、配对能耗及覆盖率继续使用原领域函数。
- 充电费用继续区分实际账单、本机手动、免费、估算、未知和币种未知；未知不转 0，不同币种不合计。
- 当前充电继续验证 `is_charging` 和当前车辆身份；未知功率不显示为 0。
- 驻车窗口继续要求完整相邻历史、充电覆盖和来源证明；未证明的窗口不进入损耗合计。
- 曲线继续使用实际采样时间、缺失断点和真实零/负值；未知采样不插值。
- 导出、PDF、分享和打开文档继续使用原数据过滤与作用域检查。

## 外部验收边界

- 桌面微信开发者工具已登录微信，但 MateLink 会话未恢复；开发者工具“已登录微信”不等于 MateLink 微信绑定完成。
- 真实手机此前存在有效 MateLink/Tesla 会话，但手机安装的是旧上传构建；本轮最新源码需通过预览二维码或体验版重新打开后才能做真机 UI 验收。
- 项目记录仍显示服务端微信 AppSecret/私有配置与 Tesla 授权回流是外部平台条件；在这些条件完成前，不宣称真实微信快捷登录或 Tesla 授权回流通过。
- 当前 Windows 主机没有连接 iOS 设备，iOS 真机预览为 `NOT_VERIFIED`。
- 微信 CLI 上传仅证明代码包进入后台版本；体验版或正式发布仍需以微信后台实际状态为准。
