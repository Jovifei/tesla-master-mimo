# MateLink Web 更新记录

网页客户端（web_matelink）版本与更新内容记录，版本号以 `web_matelink/package.json` 为准。

## 0.1.0 — 2026-11-08

本版本为网页版首次定版发布，包含两段连续工作：先按 TeslaMate 仪表盘底稿全量复刻页面，再按所有者 2026-11-08 18:39 的定版指令做收口优化。同日已部署上线（生产 bundle `index-D8hYGufl.js`，站点 https://web.teslalink.joviluma.com）。

### TeslaMate 仪表盘全量复刻

- 以 teslamate-org/teslamate 的 Grafana 仪表盘定义为底稿，23 个仪表盘逐一复刻为 21 条业务路由（总览组：总览/电量历史/状态/时间线；充电组：充电记录/充电统计；行程组：行程记录/行程统计/效率；电池组：电池健康/预计续航/驻车掉电；数据组：统计/里程/温度/地点/到访地图/软件更新/数据概况；外加远程控制/我的），界面全中文，表面沿用我方暖纸面/大圆角风格。逐面板的参数含义、数据来源与待补项见对照表 `docs/TESLAMATE-MAPPING.md`。
- 数据层补齐后端已有但网页端此前未读的字段：行程轨迹坐标与起止点、里程起止、充电坐标、桩侧用电量与交流效率 contract、逐点累计充入电量、状态实时电压/电流/固件版本。
- 新增复刻组件：弧形仪表、待补数据面板/瓷砖、数据表、高德地图面板（key 可配置、无 key 时占位、坐标 WGS-84→GCJ-02 转换）、环形构成、条形排行、充电热力图、温度包络。

### 所有者定版优化（18:39 指令）

- 总览：电量主角化（大数字 % ＋ 0–100 进度条 ＋ 预计/额定续航大数字）；充电电压/充电功率仪表撤出总览，移入充电实时区（功率优先呈现，电压/电流/电池加热仅状态快照有值时显示）；固件版本移至页面最底部；状态时间条并入总览（默认最近一周），原状态/时间线独立页删除并重定向。
- 能耗口径更正：经代码核查，App 与小程序的行程能耗为客户端本机计算，后端对原生遥测行程不提供净能耗。本版将该算法移植到网页端（`src/api/drive-energy.ts`：contract 资格校验 → 旧导入标量（标注未核验）→ 本机功率梯形积分 → 电量差 × 估算容量），效率一律本地计算。平均能耗按月平均、周平均、每个行程三档展示，并标注数据来源与可计算覆盖。
- 充电：记录列表改为逐列参数表（开始时间/地点/类型/时长/充入/用电量/效率/平均功率/峰值功率/电量变化/温度/单价/费用，共 13 列），点击行进入单次充电详情；详情瓷砖按 TeslaMate 语义配色（费用绿、时长蓝、用电量黄、效率蓝、功率橙、温度紫）。
- 行程：详情与列表参数做全（距离、时长、耗电量、平均能耗、平均/最高速度、电量变化、温度、里程表、最大功率——仅采样带功率时显示），轨迹地图保留。
- 电池健康：页面构成完全照 TeslaMate 原版重排（容量/额定续航/行程统计键值组、交直流用电量构成图、预计衰减仪表、健康度条、当前电量分段、充电统计、容量—里程关系图位）；无后端数据来源的面板保留图位并标注待补，不造数。

### 待补与已知边界

- 历史逐点电压/电流曲线、电池加热历史、电池容量与衰减序列、行程海拔、原生车驻车耗电量等暂无数据来源，页面以「待补数据」占位；后端缺口清单（10 项，按优先级）见 `docs/TESLAMATE-MAPPING.md`。
- 嵌入地图需高德 Web JS key（所有者待提供）；无 key 时地图面板显示占位与点位清单。
