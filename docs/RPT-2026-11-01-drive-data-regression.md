- 发现版本：手机 App 2.1.62/build81（源码 `debf631`），生产 API `403aa6c`。Jovi 反馈行程显示“未知”和能耗横杠；本次记录问题与处理，不等同于认定缺陷首次引入版本。

- 目前云端同时包含 Fleet 与 TeslaMate 归档；相近时间存在多条记录，但仅凭同一分钟和相近距离不能认定同一行程，不能盲目删除或合并。

## 数据与验证边界

- 两次 App 更新均为同签名 `adb install -r`，首次安装时间未改变；没有清除 Room、登录或用户费用。原自托管地址当前从手机连接超时，不自动切换数据源或覆盖其数据。
- 服务端生产候选必须以生产实际代码为基线构建；App 分支的服务端树与生产基线不同，不能用 App 工作树二进制覆盖生产。
- 修复前保留 build81 真机截图、旧截图和脱敏测试证据在本地授权目录；最终需要同时验证行程列表、详情、10 月 30/31 日真实记录、缓存/弱网与身份切换。
- 自动能耗补全仅保存经验证的派生摘要；候选为同一刷新周期共享最多 20 次详情读取的逻辑调用额度，底层 HTTP 的自动重试不计入此数。候选定向测试已通过，完整双变体、lint 与真机验证仍在进行。若此前未主动打开并缓存详情，离线时无法查看或逐点重算那条曲线。完整或较新能耗证据不会被弱估算覆盖。
- 本轮定向测试发现并修正了一个错误测试断言：真实远端新回执可新增温度单位元数据；自动补全前后原回执仍要求逐字一致。最终候选的地点投影、能耗补全、不可中断地图查询、慢充电与 Room 消费者共 55 项定向测试通过；Debug/Release 全量测试、lint、模拟器与真机验收仍需按最终候选完成。
