## 优化判断与方案

**首页**：保留青色、四个 Tab 和车型资产，压缩车模空白；电量、续航、观察时间和来源组成主卡，胎压、温度、最近行程直达。数字 / 单位 / 解释分层。显示续航不包装成实际可达承诺。设计车图是既有渲染的安全低分辨率裁切参考，正式实现继续用原始高清资源，不替换整个资产库。

**行程**：只留一组速度 / 功率 / 电量曲线入口，展开保留时间点。未知能耗不填 0，不从里程倒算真实电量。地图只使用合成路线。

**驻车**：账户、车辆、来源和记录一致时保留已有摘要，明细缺失只影响明细区域；无证据电量 / 能量显示未知。局部加载可取消，离开结束请求，不后台循环重试，不把停车空档拼成充电。

**充电**：不采用将同一会话未匹配弱化为离线提示的建议。身份未确认时隐藏不可信详情和费用编辑；匹配后才能继承同范围地址。实际账单、估算与未知分开；¥0.00 有效，不能回退成估算。

**胎压**：紧凑四轮选择器让位于趋势。单轮聚焦，文字与色彩共同表达选择。每轮独立 observedAt，旧观测不代表当前正常；未经验证历史保留但不进入真实趋势 / 提醒。Figma 三个复制曲线和数字颜色仍待修复；离线稿已验证四轮数值与曲线末端一致。

**温度**：当前值不等于历史曲线。合格车内 / 外记录用青色 / 蓝色、同单位与时间轴；单点散点，缺测断线。天气只能独立背景，不能拟合为车辆观察。缺记录时说明原因而不是伪造连续趋势。

**分析与更多**：保留既有入口，按数据分析 / 工具 / 偏好 / 诊断分组，长说明渐进展开。费用分实际 / 估算 / 覆盖率；电池健康明确模型估算而非官方检测。缺证功能仅候选布局。

**小程序**：行程、充电、统计页直接提供授权说明入口，不让用户到更多寻找登录；正常未登录不用整页红色错误。Tesla 授权、车辆确认、首次接收及可选微信确认分别表达，保持胶囊 / 安全区，不引入重型动效或扩大车型包。

## 实际 Figma 交付

三个页面：Android、小程序、设计系统。**51 个 Android 页面 / 状态画板（含 1 个弹层）+10 个小程序画板=61 个**，不是 61 项完成开发的业务功能。实际接入 **202+48=250 个点击节点**，接线时未解析目标为 0，当前选择不重复跳转。

可编辑文本、自动布局卡片、矢量图表、按钮变体、语义颜色；不是截图贴图。浅深色为两个变量集合以适配当前账户模式限制。页面边距 16、普通卡片圆角 16、主视觉 20、主操作区至少 48。画布字体是设计参考，正式实现遵循平台中文字体。

| 动效 | 毫秒 | 边界 |
|---|---:|---|
| 主 Tab | 0 | 不交叉淡入，不引回双层残影 |
| 详情 | 180 | 克制反馈，保留明确返回 |
| 胎压聚焦 | 160 | 只做选择反馈，不补造采样 |
| 导航弹层 | 240 | 可取消和关闭 |
| 减少动画 | 0 | 原生实现需全局并停止后台循环 |

Figma 已写入实际过渡与导航，但减少动画只有起点示例，不是全流程全局开关。离线稿的全局减少动画已测试。Figma 筛选、授权与输入是流程示例，不是完整状态机或可执行 OAuth。
