# MateLink 珍珠电驱动效与浅色视觉优化设计

## 已确认的目标

在原 MateLink App 的现有面板、数据、四个一级入口和页面布局基础上，提升图标质感、状态动效、面板自然度与字体一致性。

- 保留原 `com.matelink`、原数据、Dashboard、行程、充电、更多和分析页面。
- 不重做信息架构，不删除现有功能，不改变已验证的导航路径。
- 不模仿或使用 Apple 的标志、图标、截图或专有资源；只参考其浅色界面的留白、信息层级、材质与动效克制原则。

## 视觉语言：珍珠电驱

浅色底板保持现有数据工具的可读性，使用少量状态颜色和柔和材质取代高对比的外框。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 珍珠背景 | `#F5F6F8` | 页面底色与大面积留白 |
| 电驱蓝 | `#0A84FF` | 主操作、已选导航、刷新确认 |
| 遥测青 | `#0B9CAF` | 车辆在线、效率与能量数据 |
| 充电橙 | `#FF9F0A` | 充电、能量补给、注意状态 |
| 状态绿 | `#34C759` | 正常/完成状态 |
| 风险珊瑚 | `#FF5A5F` | 仅用于错误与严重提醒 |
| 香槟高光 | `#C59A5A` | 仅用于启动图标高光，不用于正文 |

面板改为白色或浅色半透明材质、轻微阴影和低对比边缘。删除“外层虚线 + 实线”的双重框感；地图、车辆和数据内容保持位置不变。

## 图标与动效

### 静态图标

Android 桌面图标保持静态。优化前景图标为青蓝电驱徽章：圆角方形、简化电能符号与车辆轨迹，不使用 Tesla 标志。

底部导航沿用现有四个标签，替换为更能表达功能的圆角线性图标：

- 仪表盘：车辆/仪表状态。
- 行程：路线与轨迹。
- 充电：电能与插枪。
- 更多：分析点阵/洞察，而不是无语义省略号。

### 应用内状态动效

| 位置 | 动效 | 时长 | 触发条件 |
| --- | --- | --- | --- |
| 启动 | 徽章高光扫过 + 电驱轨迹出现 | 0.8 秒 | 每次冷启动一次 |
| 刷新 | 图标带阻尼旋转，车辆卡轻上浮 | 0.45 秒 | 用户手动刷新 |
| 在线/充电 | 状态点轻呼吸，进度条补能 | 1.2–2.4 秒 | 状态变化或正在充电 |
| 首页数字 | 向上淡入，不做滚轮数字 | 0.22 秒 | 首次加载有效数据 |
| 地图车辆 | 一次定位波纹 | 1.2 秒 | 新位置到达 |
| 底栏 | 已选指示器滑动，图标 1.06 倍回弹 | 0.18 秒 | 切换一级页面 |
| 分析图表 | 首次可见时描线 | 0.45 秒 | 有足够数据时 |

所有动效只在状态变化或首次可见时播放；不使用无期限循环、闪烁或全屏渐变。系统关闭动画或减少动态效果时，保留最终状态而跳过过渡。

## 字体与面板

- 标题统一使用 Material 现有标题层级，不再在同一屏混用大号粗体和无语义的中号粗体。
- 数据值使用等宽数字特性；关键值最大、单位和说明次级。
- 正文与辅助说明使用统一的弱化色，不用多种灰色争夺层级。
- 面板不移动，不改变卡片内数据顺序；只调整圆角、间距、阴影、边缘对比与图标尺寸。

## 界面逻辑微调

- 保留“仪表盘 / 行程 / 充电 / 更多”四个一级入口。
- “更多”保持现有入口集合，但在视觉上明确分为分析、报告和系统，减少所有卡片同权重造成的选择负担。
- 刷新、设置和车辆状态维持原位置；动效只反馈操作成功、加载中或失败，不增加新弹窗。

## 实施范围

- Android：底部导航图标与选中动效、Dashboard 状态动效、More 与统计卡片的材质/字体一致性、启动微动效、启动图标前景。
- 预览：使用 HyperFrames 制作 6 秒无头像动效预演；使用 Remotion 输出同一视觉规格的可审核短预览。HeyGen 不进入 App 运行时，保留给后续 App Store 产品介绍视频。
- 文档与测试：增加无障碍/动效状态的 JVM 或 Compose 纯逻辑测试，记录手机截图证据。

## 不在本轮范围内

- 服务器、Tesla OAuth、车辆控制、地图路线采集、业务数据算法重写。
- 页面结构重做、标签大规模改名、删除用户配置或历史数据。
- 将动态视频作为 Android 桌面图标。

## 验收

- 原四页入口和既有数据页面仍可访问。
- 底栏图标在未选中与已选中状态均清晰，字体与触控目标不小于 48dp。
- 关键卡片没有虚线/实线双重外框；浅色和深色模式都保持对比度。
- 动效在真机冷启动、刷新、充电状态、地图位置和导航切换中可见，但静止状态不分散注意力。
- `testDebugUnitTest`、`testReleaseUnitTest`、`assembleDebug`、`assembleRelease`、`lintRelease` 与 `git diff --check` 通过；不建立 lint baseline，`MissingTranslation=0`。
