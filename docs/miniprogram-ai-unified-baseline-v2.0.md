## 二、P0 三项（已收敛）

- **P0-1 年度洞察**：Tools report + Analysis mileage 共用同一结果，文字洞察。
- **P0-2 充电洞察**：含费用叙述（并入，保留实际/估算/未知语义）；费用叙述与费率节省共享入口、不共享验收。
- **P0-3 AI 渲染**：路由 B + 可恢复任务 + 两阶段状态机（拿到 12 小时临时 URL 立即落 GENERATED；转存失败只重试下载；结果未知绝不重新调生图接口）。Canvas 优先验证分支：AI 生成背景 + 既有车辆主体（透明 PNG）叠加，功能定义为“AI 场景预览”（范围缩减，非改色/改装/多角度重绘）；“100% 保车型”改为可验收表述（主体用既有审核资产、不作生成式重绘、不改真实配置）。

## 三、路由与安全（已收敛）

- 生产环境图、文**统一走 B（云函数）**；前端不打包、不调用任何 wx.cloud.extend.AI 代码，不暴露模型名称。路由 A 仅限 Phase 0 探路脚本。
- 绕过封禁是**开放真实用户调用的硬条件**，不是 A/B 切换分水岭：Phase 0 必须验证同一普通用户直调 A 被拒绝且账单无消耗；封不住且无等效强制控制时，暂不公开真实用户 AI 调用，保留本地确定性摘要与现有图片功能。
- 降级顺序：AI 路由可用 → B 不可用/未授权/额度不足 → 本地确定性文案。生图直调基础库门槛 3.17.4（走 B 时不适用），文本 3.15.1。
- 不开放自由文本输入：首版结构化数据 + 风格枚举；服务端校验枚举，不接受任意 prompt/任意 URL。

## 四、记账、熔断与额度（已收敛）

- 生文与生图**分开记账、分开熔断**：生文耗尽后自动消耗资源点套餐（非资源点套餐直接失败）；生图耗尽直接报错，不转扣、无续包（hy-image-v3.5-preview 专属说明）。
- 85% 停止接单阈值，公式：`已结算消耗 + 所有在途/结果未知请求的预留量 + 本次最大可能消耗 ≤ 对应赠送总量 × 85%`；文字和图片各自执行，服务端原子预留；重试、模型回退、管理员测试计入；超时不立即退预留；图片按实际生成张数记账。85% 不是平台自带费用上限；基础设施（云函数/数据库/存储）另设预算保护。
- 客户端护栏（缓存、日上限、远程熔断）只称软护栏；硬约束须可信执行端原子额度账本 + 单次输出/环境并发限制 + 平台侧实际生效的调用权限。

## 五、隐私与 Consent（已收敛，第五轮定版 Consent 交互）

- 旧授权对 AI 一律视为未授权；底层字段拆分（ai_text_insights / ai_image_render）；记录可追溯（scope、consentVersion、policyDocumentHash、acceptedAtServer、withdrawnAt，绑定认证主体）；隐私政策文档正常更新版本/日期/哈希并保留历史，不强制全员重新授权；文字授权不覆盖图片处理；同一洞察跨页（年度/里程）只问一次；撤回即刻阻断对应调用并清除对应缓存。
- 隐私文档版本升级与全员重授权解耦：冷启动基础服务准入兼容旧版隐私版本号，仅首次点击 AI 功能时校验对应 scope。
- 白名单载荷：固定 schema + 严格类型/单位/范围/枚举校验 + 拒绝额外属性；正则只作补充检测；敏感字段（车辆身份、精确位置、轨迹、令牌、userId、原始 DTO、完整地址）根本不进入输入结构；检查范围含正文、图片、EXIF、文件名、参考图 URL。
- 三承诺重写版：自有处理不用于训练、不另供第三方训练；任务恢复仅暂存最小输入、终止后删除、最长 24 小时，普通日志不记完整 Prompt/输入/结果；结果与输入分开管理、保存须单独说明期限与删除方式；授权证据与最小用量审计单独保存并披露；上线前核验 CloudBase 调用链的训练用途、保留期限与安全日志条款，未取得“不用于训练”依据不向用户承诺、不开放真实用户数据调用。
- 去标签化：UI 可用中性命名（“智能数据解读/年度用车小结”），结果仍明确标识 AI 生成，提审如实披露；**绝不构成类目豁免策略**。类目判定看实际功能；类目受阻时统一降级为真正的本地确定性摘要，不采用“保留模型调用、只换文案”。

## 六、数据与模型规则（已收敛）

- 前端先计算 + 模型禁数学：占比、差值、加权平均、费用合计由业务代码完成，分母明确；Prompt 禁令只是行为指令，仍需事实 ID、关键数字替换或输出验证，不合格回退确定性文案。
- 模型组合：主 deepseek-v4.1-flash、备 hy4，须经同一批样本评估；模型名集中配置 + 受控覆盖 + 有限白名单，失效时用已验证默认值或停新生成，切换记入结果版本与缓存键。
- 缓存键：至少含用户作用域 + 车辆/数据作用域 + 功能 + 统计范围 + 规范化数据指纹 + schemaVersion + promptVersion + modelVersion；处理规范化、碰撞、隔离。
- 重试口径：文字总尝试次数不超过 2 次，仅针对明确可重试的短暂错误，覆盖 SDK 内置重试与主备切换；生图结果未知不自动重发，已生成但保存失败只重试保存。
- 超时：云函数容器超时 900 秒（确保接住 12 小时临时 URL 并落库）；前端等待提示阈值 60~90 秒，超时提示后台处理中、改轮询任务表，严禁自动重试重生成。
- 生图协议：唯一采用 messages 协议（`createImageModel('cloudbase')`，@cloudbase/ai ≥ 2.32.0），hy-image-v3.5-preview，`footnote: 'AI生成'` 原生水印；参考图单图 ≤20MB；返回 12 小时临时 URL。
- “80% 可执行”口径废弃，改用四分法：可直接开发 / 缺数据 / 需实测 / 影响上线资格。
- Taro 目录风险：函数源码位于构建清理范围之外（cloudfunctionRoot 与 dist 分离）；检查清理/发布脚本与复制规则；未看配置前不断言 BUG 已存在。
- wx.cloud.init：单例惰性初始化一次 + 环境 ID 校验，开发/测试/生产分开；初始化失败允许受控恢复；不替代授权检查。
- 并发测试方法：阶梯 1→2→5，分别记录请求速率、在途数、输入输出量、延迟、错误分类；五并发成功 ≠ 五 QPS；429 原因结合实际错误判断。
- 本地保存合法：仅本机保存（最近 10 张）是合法交付方案；条件：单图/总字节预算、下载域名与失败处理、Canvas 导出后保存为本地用户文件、保存成功后更新索引、失效状态真实显示、相册保存单独授权；重编码后复查 AI 显式与隐式标识；12 小时空窗纯本地方案无法可靠保证，须如实告知；“零云存储”≠“零成本”。
