MateLink 使用说明

MateLink 用于查看用户自托管 TeslaMate 兼容服务提供的车辆数据。它是独立第三方项目，不是 Tesla 官方应用。

连接配置

只需填写两项：服务器地址和 API Key。服务器地址只填服务根地址，例如 https://api.example.com 或可信局域网的 http://192.0.2.10:8080。不要追加 /api/v1 或其他接口路径。

先点击“测试连接”；测试不会保存输入。确认结果后，点击“保存配置”才会保存。

常见问题

401 通常表示 API Key 无效或与该服务器不一致。服务不可达时，请核对根地址、端口、局域网连接和服务运行状态。局域网 IP 可能会变化。

TeslaMate Web 与 Grafana 是管理和可视化界面；MateLink 需要连接的是 MateLink API/兼容 API 根地址。

不要截图、公开分享 API Key。HTTP 未加密，仅应在可信局域网中使用。驾驶过程中请勿操作 App。

MateLink 是独立第三方项目。
