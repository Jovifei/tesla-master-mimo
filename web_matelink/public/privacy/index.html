MateLink 隐私政策

版本：2026-08-21。生效前提：运营主体、联系邮箱、投诉渠道、部署地域和第三方 SDK 清单已在正式 HTTPS 页面补全；在此之前不开放 Tesla 云端授权。

1. 我们处理的信息

在用户主动授权后，服务端处理 Tesla OpenID 标识的不可逆关联值、加密 Tesla 授权令牌、JourVolt 会话、车辆标识与只读车辆状态。行程、充电与分析数据仅从连接之日开始采集；应用不读取 Tesla 账户密码或邮箱。

2. 目的与必要性

这些信息仅用于完成 Tesla 授权、建立会话、展示用户自己的车辆数据、提供用户选择的统计分析、处理安全故障和响应删除请求。没有用户的单独同意，不开启地图、路线或精确位置采集；拒绝位置处理不影响基础只读车辆功能。

3. 保存与删除

原始高精度位置点计划最多保存30天，简化路线和行程摘要最多保存1年；具体功能未启用时不会开始相应采集。用户可以删除单条行程、关闭采集、退出登录或注销账号。注销会删除在线账号、会话、加密 Tesla 令牌及云端车辆数据；加密备份将在最多30天的自然轮换期后过期。

4. 共享与跨境

为完成授权，信息会与 Tesla 官方服务交互。地图功能开启后，车辆位置仅发送给用户已同意的境内地图服务。公开版不把精确车辆坐标发送给 Nominatim、Open-Meteo 等境外服务。除法律要求或取得另行同意外，不出售或用于广告定向。

5. 安全措施

服务端令牌加密保存，刷新令牌以事务方式轮换；日志不得包含令牌、VIN、精确坐标或 Tesla 账号。应用仅保存 JourVolt 会话，并通过 HTTPS 访问云端服务。任何系统都无法保证绝对安全，发生风险事件时将依法处理和通知。

6. 用户权利与联系

用户可在应用设置中查看账号状态、退出、重新授权和注销。正式公测前，本节将补充运营主体、联系邮箱、投诉渠道、数据保护联系人和处理时限；这些信息未补齐前，Tesla 云端授权保持关闭。

MateLink 是独立第三方项目。
