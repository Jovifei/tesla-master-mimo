MateLink 用户协议

版本：2026-08-21。生效前提：本页已由服务运营者在正式 HTTPS 域名公开发布，并在应用内可访问。

1. 服务说明

MateLink 仅提供只读的车辆状态、行程、充电和数据分析展示。它是独立第三方产品，不属于 Tesla 官方产品，也不提供远程车控、充电命令、哨兵视频或历史录像功能。

2. Tesla 授权

用户选择“使用 Tesla 登录”后，将在 Tesla 官方页面输入账户、密码和多因素验证信息。MateLink 不接收或保存 Tesla 密码；应用仅保存 JourVolt 会话，Tesla 授权令牌仅由服务端加密保存。用户可在设置中退出、重新授权或注销账号。

3. 使用条件

用户应拥有对应车辆和 Tesla 账号的合法授权，并对其账户、设备及网络环境负责。不得利用本服务访问他人车辆数据、绕过 Tesla 授权或进行任何违法活动。

4. 数据与准确性

数据可能来自 Tesla Fleet API、Fleet Telemetry、TeslaMate 或本地计算。页面会区分观测值、派生值、估算值、采集中和不可用状态；数据不应作为驾驶安全、维修、保险、金融、法律或紧急决策的唯一依据。

5. 服务变更与停止

技术公测不承诺生产级可用性。为安全、合规、Tesla API 限额、故障处理或服务终止所必需时，运营者可以暂停相应功能，并将通过应用或本页说明。

6. 联系与争议

邀请制技术公测开启前，运营主体名称、联系邮箱和投诉渠道必须填写并发布在本页；在此之前不会开启 Tesla 云端授权。适用法律和争议处理方式以届时公开的正式版本为准。
