# Interaction position artwork

`vehicle-position.png` is a deterministic 240×460 transparent 128-colour render of
`docs/design/vehicle-position-schematic.svg`. SHA-256: `435a84f40faa5459b9c0a4084d84f8f21207e4e3ea9e8fde2209fa529a4a067a`.
This neutral four-wheel/door-position diagram is not a Tesla model identification
or the user's vehicle photo. Existing packaged Tesla catalogue images remain the
vehicle hero source. Values, labels and warning states are rendered by components,
not baked into pixels. No external image downloads or user-data writes are added.
