# MateLink 微信小程序变更记录

## 0.2.2 · 2026-09-14

- 收口 Tesla 授权事务的领取、取消、退出和页面卸载竞态；旧回包不能恢复已切换的账号或覆盖新的事务。
- 授权状态补齐失败、取消、已领取和短 ticket 过期回查；微信回流只携带 callback reference，不接受裸 ticket。
- 历史分页区分合法已加载前缀与全部完成，异常页不推进成功水位；缓存长期身份与会话代次分离，并提示本机写入失败。
- 收紧官方授权 URL 路径校验，移除小程序业务代码对 `URL`/`URLSearchParams` 的运行时依赖；版本构建产物继续不包含密钥或令牌。

## 0.2.1 · 2026-09-13

- 页面请求按账号、会话代次和当前 stable vehicle 隔离，切车、隐藏、退出和详情乱序不会回写旧数据。
- 历史合并保留来源与质量证据，更新 canonical public ID，检查分页完整性，并在缓存写入失败时明确提示。
- 微信 Tesla 授权改为事务 proof、状态回查和一次性领取；回流不再把可兑换 ticket 放进 URL，退出会取消待处理事务。
- 授权事务的 grant、ticket、微信关联和领取状态在服务端同一数据库事务中完成。

## 0.2.0 · 2026-09-13

- 接入服务端微信会话交换、一次性 Tesla 账号关联和官方授权回流。
- 增加会话刷新、退出、隐私授权前置检查、账号与车辆作用域保护。
- 车辆页改为读取 `telemetry` 就绪项，显示车型、状态、位置、来源和观测时间，并保留安全重试入口。
- 行程与充电页接入分页、详情、当前充电和按账号/稳定车辆隔离的本地历史缓存。
- 空响应、缺失字段、历史质量和服务端错误继续按真实证据显示，不生成示例数据。

真实微信 AppID、业务域名、Tesla 官方授权、虚拟钥匙和首个 MQTT 事件仍需在平台与真机完成验收。
