# MateLink 微信小程序变更记录

## 0.6.7 · 2026-11-06

- 全面落地 Apple 风格（Apple Human Interface Guidelines）UI 重构体系：
  - 新增 `apple-tokens.scss` 设计令牌规范体系：系统间距刻度（8/12/16/24/32/40/48rpx）、平滑连续圆角（14/20/28/36/999rpx）、iOS 级语义灰阶色板、暗黑模式自动自适应、Hairline 细分割线及微动效缓动参数。
  - 列表视觉彻底告别「卡片墙（Card Wall）」，转向 iOS Inset Grouped 分组式列表，外层整组圆角包裹，内部使用细发丝线分隔，大幅降低视觉噪点并提升滑动流畅度。
  - 核心遥测数字（SOC、续航、功率、时速、费用等）全面接入等宽表格数字（Tabular Figures `font-variant-numeric: tabular-nums` 与 `font-feature-settings: "tnum" 1`），在动态刷新中整齐稳定不跳动。
  - 「更多」页重构为原汁原味的 iOS 系统设置风格分组列表（带圆角图标、清晰分类标题、单行微交互、右侧指示箭头），结构层次分明。
  - 仪表盘与车辆状态区重构：Hero 车辆展示增加克制留白，状态胶囊微调为 Apple Capsule Pill，远程控制与扩展状态归一化为精致触觉反馈面板。
- 全量自动化测试保持 100% 绿灯（79 个测试文件、994 项单元测试 PASS、6 项车辆资源测试 PASS、TypeScript 0 错误、生产构建 197 文件 PASS）。

## 0.6.6 · 2026-11-06

- 仪表盘与车辆状态全面对齐原生 App：
  - 新增车队扩展状态行渲染：媒体播放状态（曲目/艺术家/来源/状态）、车机固件升级状态（阶段与百分比）、按计划出发与定时充电预告、代客模式与限速状态、主副驾空调设定温度。
  - 新增车辆远程控制群组（车锁与车寻、空调温控与车窗控制、充电限值与充电口开关、哨兵模式开关），配套二次确认弹窗、温度调节器、充电限值滑块及指令执行状态药丸提示。
  - 新增附近充电站推荐卡片与常用地点（家庭/公司等自定义经纬度地点）管理支持。
- 驻车与待机能耗分析全面对齐原生 App：
  - 行程列表与驻车详情新增驻车待机能耗分析卡片（60 kWh 基准能耗推算、待机功率瓦特、预估消耗续航、状态智能推断）。
  - 驻车详情标题区集成 `≈0.60 kWh · 预估消耗续航 ≈4 km · 待机功率 ≈320 W` 摘要指标。
- 充电历史与明细页面对齐原生 App：
  - 充电历史区间统计卡片新增「平均电价」（¥/kWh）与「单次平均」（kWh/次）双维度宏观指标。
  - 充电历史单条记录丰富单价与平均功率指标。
  - 地址层级智能推导与美化格式化对齐，提升多级行政区划可读性。
- 全量测试 79 个测试文件、994 项单元测试通过，TypeScript 类型检查零错误，车辆资源完整性通过，Taro 4.2.1 生产构建成功。

## 0.2.2 · 2026-09-14

- 收口 Tesla 授权事务的领取、取消、退出和页面卸载竞态；旧回包不能恢复已切换的账号或覆盖新的事务。
