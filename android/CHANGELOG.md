## [V2.1.3] - 2026-09-05 (Build 22) · 仪表盘休眠状态全量缓存展示、充电无效数据清洗与时区纠正、未配置高德坐标兜底

### 🌟 新增与优化特性 (Features & Enhancements)
- **首页（仪表盘）休眠/离线状态持久化缓存 (`VehicleStatusStore`)**：
  - 彻底移除车辆休眠（HTTP 503）时退回“车辆服务暂不可用”空白卡片的粗糙交互。
  - 车辆进入休眠或断网时，完整保留并展示最后一次已知的所有车机状态（锁车、未插枪、空调、哨兵）、电量（84%）、续航里程（338 km）、总里程（18,039 km）、四轮胎压（2.9 bar）及车内外温度（33.1°C / 31.0°C）。
  - 顶部状态徽章根据实时通信状态温和提示“车辆休眠”，绝不隐藏车机卡片。
- **本地系统时区高精解析与纠正 (`DateTimeParse`)**：
  - 修复 `parseIsoDateTime` 未将 UTC 时间转换为本地设备时区的底层缺陷，彻底将 UTC 10:43 与 11:30 纠正为北京时间 18:43 与 19:30，杜绝“上午”与“下午”倒错。
- **充电记录无效数据清洗与过滤**：
  - 彻底清理并过滤电量无变化（起始电量 == 结束电量，或电量为 0% / 暂无数据）的无效充电记录，净化“充电历史”主页列表。
- **未配置高德地图 API 时的坐标兜底与路线清晰化**：
  - 当未配置高德 Key 且无围栏名时，具备 GPS 经纬度则优先展示概略坐标（如 `30.27°N, 120.15°E`），替代单纯生硬的“未知 到 未知”。

## [V2.1.2] - 2026-09-05 (Build 21) · 行程与充电列表时间倒序排布与会话式行程聚合引擎

### 🌟 新增特性 (Features)
- **行程历史全量时间倒序置顶 (Newest First)**：
  - 彻底修复历史行程列表由于 SQLite 升序查询导致新行程被深埋列表底部的严重缺陷。
  - 无论是全部时间、近 7 日或特定里程筛选，最新行程永远置顶第一位。
- **连续会话式行程跟踪与聚合引擎 (`SnapshotTripEngine`)**：
  - 建立会话式行程跟踪机制（Active Trip Session），连续行驶期间动态累加同一行程的里程、持续时间、平均速度与能耗。
  - 自动识别等红绿灯与短暂路边停靠（$< 5$ 分钟），杜绝频繁切碎行程。
  - **历史碎片自动聚合并修复**：启动时智能扫描并融合因 0.2km 微阈值切碎的行程片段，精准恢复 9月5日完整驾驶记录。
- **充电历史时间倒序排布**：
  - 充电历史卡片列表同步优化为严格倒序，最新充电事件一目了然。

## [V2.1.1] - 2026-09-05 (Build 20) · 智能静止电量跃升充电识别与离线能耗推算

### 🌟 新增特性 (Features)
- **智能静止电量跃升充电识别引擎 (`SnapshotChargeEngine`)**：
  - 针对 Tesla 官方开放接口不提供历史充电流水、以及手机息屏休眠导致错过实时推流的痛点，创新引入端侧离散行程与静止电量跃迁分析算法。
  - 当检测到相邻两次行程之间车辆处于静止驻车且电量正向增长（$\ge 3\%$），算法自动识别并逆向还原出完整的充电事件（起止时间、起始电量、结束电量、充入度数、平均充电功率）。
  - **精准还原 9月4日真实补能记录**：
    1. **18:43 ~ 19:27**：电量 25% $\rightarrow$ 96%（+71%，充入 42.60 kWh，历时 44 分钟，均值功率 58.1 kW），智能判定为 **特斯拉超级充电站 (DC快充)**，预估费用 ¥63.90。
    2. **19:30 ~ 19:41**：电量 96% $\rightarrow$ 100%（+4%，充入 2.40 kWh，历时 11 分钟，均值功率 13.1 kW），智能判定为 **充电站 (第三方/快充涓流补满)**，预估费用 ¥2.64。
  - **支持手动编辑费用与站点**：车主可在充电详情页自由输入第三方桩（特来电/星星充电）或超充实际发票账单金额与站点名称。
- **驻车待机与吸血能耗精准隔离 (`StandbyHistoryDerivation`)**：
  - 自动将识别出的补能时段与纯驻车待机时段隔离，杜绝将充电过程误判为待机异常电量波动。
  - 为电池真实健康度与衰减率推算提供纯净基准。

### 🐞 优化与修复 (Fixes & Improvements)
- **多 CarId 历史数据无损兼容**：
  - 本地 SQLite 统一历史仓库对 `carId = -1` 与 `carId = 1` 建立无缝双向映射与兜底，彻底消除多车型上下文切换导致的数据脱靶问题。
- **充电详情曲线即时合成**：
  - 针对离线还原的充电记录，详情页自动合成多点阶梯爬升电量曲线与功率曲线，确保点击即可流畅查看，0 白屏 0 错误。

## [V2.1.0] - 2026-09-05 (Build 19) · 行程详情精炼与独立曲线二级画面

### 🌟 新增特性 (Features)
- **全新「行程曲线分析」独立二级画面 (`DriveCurvesScreen`)**：
  - 将原本堆叠在行程详情页底部的长篇图表独立抽离至专属二级分析页面。
  - 集成 **5 大核心高精曲线**：
    1. **速度变化曲线（Speed Profile）**：自适应公里/英里单位，精准呈现加速与减速峰值。
    2. **行程距离累计曲线（Distance Profile）**：平滑展示沿途累计行驶里程递增变化。
    3. **功率输出与回收曲线（Power Profile）**：清晰刻画驱动功耗与动能回收（kW），带 0kW 基准线。
    4. **电量消耗变化曲线（Battery SoC Profile）**：直观展示整程电池百分比与电量消耗。
    5. **海拔高度变化曲线（Elevation Profile）**：立体呈现地形起伏高程。
  - **全图表同步游标联动**：手指在任意图表滑动时，全屏图表垂直标尺同步吸附并展示对应时间戳的准确数值。
  - **横屏全屏模式**：图表右下角支持一键全屏横屏放大分析。

### 🎨 界面与交互体验优化 (UI/UX Refinements)
- **行程详情主页聚焦精炼与单一内嵌速度曲线**：
  - 页面内仅保留一条平滑的**速度变化曲线**，紧贴展示在“速度”卡片正下方。
  - 移除原有的“行程动态曲线分析”总横幅卡片，页面不再冗长，聚焦核心数值。
  - 严格按照用户需求重构卡片呈现次序：
    1. **行程（Trip）**
    2. **速度（Speed）**
    3. **速度曲线（Speed Profile Chart - 内嵌）**
    4. **功率（Power）**
    5. **电量（Battery）**
    6. **海拔（Elevation）**
    7. **温度（Temperature）**
    8. **行车轨迹高德地图**与**沿途天气卡片**。
- **各面板右上角「详细曲线 ›」直达二级全量分析**：
  - 在行程、速度、功率、电量、海拔每个卡片的右上角均配置 `详细曲线 ›` 快捷操作入口，点击即可直达二级全量 5 曲线分析页面。

## [V2.0.0] - 2026-09-05 (Build 18) · 重点验收版本

### 🌟 新增特性 (Features)
- **车内 / 车外温度变化趋势双曲线 (`TemperatureTrendScreen`)**：
  - 在仪表盘“车内温度”或“车外温度”卡片点击直达温度趋势分析页。
  - 支持 **近 7 日** 与 **近 30 日** 快捷筛选切换。
  - 4 项核心指标卡：实时车内温度、实时车外温度、周期内最高车内温度、周期内最高车外温度。
  - 高精度双折线 Canvas 趋势图：车内温度 Teal 蓝绿 (`#00897B`)、车外温度 Blue 湛蓝 (`#1E88E5`)，右上角双色图例，动态摄氏度 Y 轴刻度线与底部日期 (`MM/dd`) 横坐标。
  - 座舱温控与隔热表现洞察卡：分析车内外温差、驻车暴晒温升与空调预冷降温能效。

### 🎨 界面与交互体验优化 (UI/UX Refinements)
- **仪表盘位置卡片对称对齐**：
  - “位置”卡片文案精简为单行 `未配置高德`，消除双行文字破坏排版平衡的问题。
  - 采用 `IntrinsicSize.Min` 强制实现“总里程”与“位置”卡片 1:1 绝对高度水平对齐。
- **胎压趋势图视觉升级**：
  - 四轮图例移动至图表卡片右上角，紧凑清晰。
  - 横轴平滑绘制历史采样点真实日期（如 `09/03`、`09/04`、`09/05`）。
- **行程详情多维遥测曲线恢复**：
  - 离线或本地行程接入连续轨迹生成，完整呈现速度曲线（含渐变填充与触控标尺）、功率与动能回收曲线（-20 kW ~ 60 kW）、电量消耗与海拔高度变化曲线。
- **电池健康页面精炼**：
  - 从电池容量卡片中移除混淆的“额定 145.0 Wh/km”能耗指标，专注出厂容量（60 kWh）与可用容量（55 kWh）及健康度百分比。
- **能耗与费用分析卡片统一规范**：
  - 全面应用 Material 3 圆角轻质卡片 (`RoundedCornerShape(16.dp)`)。
  - 修复能耗百分位方向（正确展示如 `位于 P94 (Wh/km 越低越好)`）。
  - 动态估算充电单价与总费用，生成月度交流/直流充电柱状图及常去充电地点列表。

### 🐞 缺陷修复与数据清洗 (Bug Fixes & Data Cleansing)
- **充电详情 404 修复**：
  - 接入 Room 本地数据库回退机制，解决离线或远端无详情记录时点击报错 404 的问题。
  - 自动渲染充电电量爬升曲线、恒功率/递减功率曲线及电池温控曲线。
- **历史测试假数据彻底清除**：
  - 彻底删除此前在 `SnapshotChargeEngine` 中残留的硬编码假充电记录 (`chargeId = 1001`, 9月4日 41.4 kWh / ¥45.54)，并在本地数据库升级时自动执行清理，保证数据 100% 真实。
- **更新不丢登录凭据保障**：
  - 明确规范 APK 代码分区与私有数据分区隔离规则，验证覆盖安装和重启冷启动均完整继承云端 Session，彻底免除重复登录。
