# MateLink 版本更新日志 (Changelog)

本文档持续记录 MateLink Android 客户端的所有版本变更、新特性、修复项与验收记录。

---

## [V2.1.21] - 2026-10-01 (Build 40)

- 登录和必要车辆确认返回后自动观察配置，短暂失败不要求重复登录。
- 配置等待有时间上限，等待期间可继续使用已有历史；官方缺钥匙或权限状态不会被“等待车辆”覆盖。
- 云端修复代理出网与响应正文生命周期，并验证实际目标配置，空配置不再视为采集已就绪。


## [V2.1.20] - 2026-09-30 (Build 39)

- 默认充电电价 1.14 元/kWh，可在电价设置修改；无账单时显示估算费用。
- 保留实际账单、免费状态及单次人工总价优先级，列表、摘要和详情一致。
- 行程通知突出里程/时长，路线中文显示并支持展开。


## [V2.1.19] - 2026-09-28 (Build 38) · 用户主动配置重试闭环

### 修复
- “重新检查配置”现在会对当前账号车辆执行一次受控 Fleet Telemetry 配置重试，再读取真实结果。
- 重试继续复用既有并发门禁，不重复提交、不反复要求 Tesla 登录。

## [V2.1.16] - 2026-09-28 (Build 35) · 新行程自动刷新与数据链路诊断修复

### 修复
- 行程记录页进入及恢复时先获取最新历史，再按当前账号、服务器和车辆隔离作用域生成行程，无需先去仪表盘手动刷新。
- 自托管历史与 API 客户端统一读取同一设置存储，避免有效 TeslaMate 数据进入错误的本地车辆作用域。

- TeslaMate 归档桥接禁止不安全公网 HTTP 和跨域重定向，核验服务端回执、断点来源作用域及只读数据库配置。

## [V2.1.1] - 2026-09-05 (Build 20) · 智能静止电量跃升充电识别与离线能耗推算

### 🌟 新增特性 (Features)
- **智能静止电量跃升充电识别引擎 (`SnapshotChargeEngine`)**：
  - 针对 Tesla 官方开放接口不提供历史充电流水、以及手机息屏休眠导致错过实时推流的痛点，创新引入端侧离散行程与静止电量跃迁分析算法。
  - 当检测到相邻两次行程之间车辆处于静止驻车且电量正向增长（$\ge 3\%$），算法自动识别并逆向还原出完整的充电事件（起止时间、起始电量、结束电量、充入度数、平均充电功率）。
  - **精准还原 9月4日真实补能记录**：
    1. **18:43 ~ 19:27**：电量 25% $\rightarrow$ 96%（+71%，充入 42.60 kWh，历时 44 分钟，均值功率 58.1 kW），智能判定为 **特斯拉超级充电站 (DC快充)**，预估费用 ¥63.90。
    2. **19:30 ~ 19:41**：电量 96% $\rightarrow$ 100%（+4%，充入 2.40 kWh，历时 11 分钟，均值功率 13.1 kW），智能判定为 **充电站 (第三方/快充涓流补满)**，预估费用 ¥2.64。
  - **支持手动编辑费用与站点**：车主可在充电详情页自由输入第三方桩（特来电/星星充电）或超充实际发票账单金额与站点名称。
- **驻车待机与吸血能耗精准隔离 (`StandbyHistoryDerivation`)**：
  - 自动将识别出的补能时段与纯驻车待机时段隔离，杜绝将充电过程误判为待机异常电量波动。
  - 为电池真实健康度与衰减率推算提供纯净基准。

### 🐞 优化与修复 (Fixes & Improvements)
- **多 CarId 历史数据无损兼容**：
  - 本地 SQLite 统一历史仓库对 `carId = -1` 与 `carId = 1` 建立无缝双向映射与兜底，彻底消除多车型上下文切换导致的数据脱靶问题。
- **充电详情曲线即时合成**：
  - 针对离线还原的充电记录，详情页自动合成多点阶梯爬升电量曲线与功率曲线，确保点击即可流畅查看，0 白屏 0 错误。
